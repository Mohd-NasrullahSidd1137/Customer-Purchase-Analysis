# 🛍️ Customer Purchase Analysis

## 📌 Project Overview

This project focuses on analyzing customer purchase data to understand customer spending behavior, popular products, purchase frequency, and buying patterns.

Using Python and data analysis libraries, the project transforms sales transaction data into meaningful insights that can support better business decisions.

## 🎯 Project Objectives

- Analyze customer-wise total spending.
- Identify the top 10 highest-spending customers.
- Discover popular products based on quantity sold.
- Understand monthly customer purchase trends.
- Analyze customer purchase frequency.
- Segment customers into low, medium, and high spending groups.
- Compare customer purchases across product categories.
- Generate business insights from sales transaction data.

## 🛠️ Tools & Technologies

- **Python** — Data analysis
- **Pandas** — Data manipulation and aggregation
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical charts
- **Jupyter Notebook** — Interactive analysis environment
- **Microsoft Excel** — Source dataset

## 📊 Analysis Performed

### 1. Customer Spending Analysis
Calculated total spending, number of unique orders, total quantity purchased, and average order value for each customer.

### 2. Top 10 Customers
Identified the highest-spending customers and visualized their total spending using a bar chart.

### 3. Popular Products
Analyzed products based on quantity sold, revenue, and unique orders.

### 4. Monthly Purchase Trends
Analyzed monthly revenue, purchase activity, quantity sold, and unique customers.

### 5. Purchase Frequency
Examined how many unique orders customers placed to understand repeat purchasing behavior.

### 6. Customer Segmentation
Grouped customers into low, medium, and high spending segments based on their relative spending levels.

### 7. Category Analysis
Compared product categories by total revenue, quantity sold, and number of unique customers.

## 💡 Business Value

This analysis helps businesses understand:

- Which customers contribute the most revenue.
- Which products are most popular by quantity sold.
- How customer activity changes over time.
- How frequently customers place orders.
- How spending differs across customer segments.
- Which product categories attract more customer purchases.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn openpyxl jupyter
   ```

4. Keep the Excel dataset in the same directory as the notebook.
5. Open `Customer_Purchase_Analysis.ipynb` in Jupyter Notebook.
6. Run the notebook cells from top to bottom.
7. Review the generated tables, charts, and CSV outputs.

## 📁 Dataset Information

The analysis uses a sales transaction dataset containing customer IDs, order dates, products, categories, quantities, revenue, and profit-related information.

The dataset is synthetic and was generated for educational and analytical practice. It does not represent actual customer transactions from a real business.
